# URL Extractor for NotebookLM

Chrome 拡張として、note.com と YouTube の検索結果やチャンネル動画一覧から URL をまとめて抽出し、NotebookLM などに投げ込むためのソース収集を高速化します。すべての処理はブラウザ内で完結し、外部サーバーとは通信しません。

## 主な機能
- note.com の検索結果を走査し、記事 URL / タイトル / いいね数 / 投稿日時を取得（価格表示がある有料記事は自動除外）
- YouTube の検索結果・チャンネル動画一覧を走査し、動画 URL / タイトル / 視聴回数 / 投稿日時 / チャンネル名を取得（ショート動画はデフォルトで除外）
- 取得件数の上限を 50 件 or 300 件から選択可能。上限到達時はそれ以上の走査を停止
- URL 完全一致での重複排除
- 並び替え（エンゲージメント、投稿日、いいね・視聴回数、元ページ順）
- クリップボードコピー（選択 URL のみ）
- txt / csv ダウンロード（CSV は分析用カラムを網羅）
- エンゲージメント（勢い）を分・時間・日単位で計算し、近似換算を明示

## インストール（デベロッパーモード）
1. 本リポジトリをクローンまたは ZIP ダウンロードして展開します。
2. Chrome で `chrome://extensions/` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本プロジェクトの `extension/` ディレクトリを指定します。
4. 拡張機能アイコン（パズル型）からピン留めすると使いやすくなります。

## 使い方
1. note.com もしくは YouTube で検索結果ページ（または YouTube のチャンネル動画一覧）を開きます。
2. 拡張機能アイコンをクリックすると自動でスキャンが始まり、ポップアップ内に結果が表示されます。
3. 必要に応じて以下を操作します。
   - **最大取得数**: 50 / 300 件から選択。上限到達後は追加取得を行いません。
   - **勢いの単位**: minute / hour / day で切り替え。相対表記からの換算は「か月/年」だけ近似値として `engagement_time_is_approx=true` をセットします。
   - **並び替え**: エンゲージメント優先、投稿日優先、いいね・視聴回数優先、元ページ順を切替。
   - **YouTube ショート除外**: デフォルト ON。必要ならチェックを外してください。
4. 欲しい URL にチェックを入れた状態で、以下のエクスポート方法を選択します。
   - **コピー（選択 URL）**: URL だけをクリップボードへ即コピー。
   - **txt ダウンロード**: 選択 URL だけのテキストファイルを保存。
   - **csv ダウンロード**: 下記カラムを含む CSV を保存。

## CSV カラム仕様
| 列名 | 内容 |
| --- | --- |
| source | note / youtube |
| url | 抽出 URL |
| title | タイトル |
| channel_name | YouTube のみ。note は空欄 |
| like_count | note のみ。YouTube は空欄 |
| view_count | YouTube のみ。note は空欄 |
| publish_datetime_raw | ページ上の表示文字列 |
| publish_datetime_iso | ISO 形式に正規化できた場合のみ。変換不可なら空欄 |
| engagement_unit | minute / hour / day（ポップアップの選択に準拠） |
| engagement_value | (いいね数 or 視聴回数) ÷ 経過時間。計算不可なら空欄 |
| engagement_time_is_approx | 相対表記の「か月/年」を 30 日/365 日換算した場合 true、厳密に取れた場合 false、計算不可なら空欄 |

## トラブルシューティング
- **URL が見つからない / 件数が少ない**: ページを最後まで読み込み（必要ならスクロール）してから「再スキャン」を押してください。
- **YouTube で動かない**: 検索結果かチャンネル動画一覧ページで実行してください。ページ遷移直後はリロード後に再スキャンしてください。
- **note の有料記事が混ざる**: 価格表示を含むものは除外しますが、メンバーシップ限定記事は仕様上混入する可能性があります。

## ディレクトリ構成
```
extension/
  manifest.json      # Manifest V3 定義
  popup.html         # ポップアップ UI
  popup.js           # スキャン実行・整形・エクスポートのロジック
  popup.css          # ポップアップのスタイル
  content-scan.js    # note / YouTube の DOM から情報を抽出するスキャナ
LICENSE               # Apache-2.0
README.md             # 本ファイル
```

## プライバシー
- すべての処理はブラウザ内で完結します。
- 外部サーバーへの通信は一切発生しません。
